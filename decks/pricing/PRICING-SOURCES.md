# Pricing deck - data sources

## Rate card (slide 2)

Numbers cross-checked against `.claude/skills/alex-writing-style/references/02_products_pricing.md`
and the "AI Central Sales Playbook v3" (Q1 2026) Alex shared directly on
9 Sep 2026 - the two agree on every figure.

**Newsletter Main Ad** - one price ladder, runs on both AI Central
Newsletter (LinkedIn) and (thecentral.ai) at once: 1 ad $1,299
(30,000 impr, 200 clicks) · 3 ads $3,699 (90,000 impr, 600 clicks) · 5 ads
$5,499 (150,000 impr, 1,000 clicks). Condensed from the source docs' 5
discrete tiers (1-5 ads) to 1/3/5, matching the convention the media kit's
own hidden priced ebook slide already used for its bundle.

**Repriced 10 Sep 2026, per Alex.** Originally shown as two separate
per-channel ladders (LinkedIn cheaper at every tier: $899/$2,499/$3,799 vs
beehiiv's $1,299/$3,699/$5,499), which Alex flagged as confusing - LinkedIn
Newsletter has far more subscribers (181K+ vs 97K+) yet was priced lower.
Checked actual average delivered performance (../media-kit/MEDIA-KIT-SOURCES.md):
LinkedIn averages 300 unique ad clicks per placement, beehiiv averages 312 -
functionally the same, so the bigger list had no business being priced
lower. LinkedIn Main Ad now uses the exact same ladder as Beehiiv Main Ad,
eliminating the channel split (and the Channel column) entirely - one
price, both channels. Full repricing note (and the researched rationale)
lives in `.claude/skills/alex-writing-style/references/02_products_pricing.md`.
This is Claude's own researched fix, done at Alex's explicit request
("let's invent and research"), not independently re-confirmed tier by tier
- revisit if any number here doesn't match his intent.

**KNOWN UNRESOLVED:** the Bespoke Ebook bundle below ($999/$2,799/$4,499)
was priced as a small upsell over the OLD $899 LinkedIn Main Ad rate -
at the new $1,299 rate that bundle is now cheaper than the Main Ad it
contains, which never makes sense as a bundle. Left unchanged pending
Alex's call; the media kit's own live Bespoke Ebook slide uses the same
untouched bundle numbers, so this deck and that slide are still
consistent with each other, just internally odd. See
`02_products_pricing.md`'s own note on this.

**Bespoke Ebook / LinkedIn Carousel + Main Ad** - bundle tiers, unchanged
and identical to the media kit's hidden priced ebook slide: 1 ebook + 1
Main Ad $999 (20,000 impr) · 3 + 3 $2,799 (60,000 impr) · 5 + 5 $4,499
(100,000 impr). See "KNOWN UNRESOLVED" above.

**Priced on request** - no source document has ever put a number on these
five: Newsletter Secondary Ad, Dedicated Issue, Welcome Sequence, Website
Banner, Social Media Post. Descriptions on the slide match the media kit's
advertising-options slide verbatim. Flag if real prices exist for any of
these - do not invent figures.

**Discount policy** - 10% off for new clients, up to 5% off discretionary,
per `02_products_pricing.md`, applies across all products.
