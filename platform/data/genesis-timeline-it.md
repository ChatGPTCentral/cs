Ogni riga qui viene dal file storia originale, citato tra parentesi - `verificato`
significa trovato in una mail o evento di calendario reale, `per Alex` significa
raccontato da lui direttamente, non altrimenti provabile dalla mailbox. Il file
canonico in inglese, organizzato per temi invece che per data, resta in
`.claude/skills/ai-central-genesis/SKILL.md` nel repo - questa pagina è la
lettura di lavoro, in italiano, per la revisione dal vivo.

Correzioni: usa [Feedback](/feedback), o dimmelo in chat - le porto sia qui
sia nel file inglese.
